# Power BI Dashboard Setup Guide for WeatherFlow

This guide provides step-by-step instructions for importing the **Gold Layer datasets** generated by WeatherFlow into **Microsoft Power BI Desktop** to build an interactive, portfolio-ready weather analytics dashboard.

> [!NOTE]
> WeatherFlow generates 4 clean, pre-modeled Gold datasets in the `data/gold/` folder ready for immediate import:
> 1. `powerbi_weather_model.csv` — Full denormalized star schema fact table.
> 2. `monthly_weather_summary.csv` — Monthly aggregated temperature and rainfall.
> 3. `station_performance_metrics.csv` — Weather station geolocation and completeness.
> 4. `seasonal_analysis.csv` — Seasonal climate profiles.

---

## Step 1: Import Data into Power BI Desktop

1. Open **Power BI Desktop**.
2. Click **Get Data** $\rightarrow$ **Text/CSV**.
3. Navigate to your project folder: `weatherflow/data/gold/`
4. Select `powerbi_weather_model.csv` and click **Load**.
   *(Optionally, import the other CSVs if you want individual dimension tables).*
5. Click **Transform Data** (Power Query Editor) to verify data types:
   - `observation_date`: **Date**
   - `year`, `month`, `quarter`: **Whole Number**
   - `temp_avg_c`, `temp_max_c`, `temp_min_c`: **Decimal Number**
   - `precipitation_mm`, `wind_speed_kmh`, `humidity_pct`: **Decimal Number**
   - `station_id`, `station_name`, `state`, `season`: **Text**
6. Click **Close & Apply**.

---

## Step 2: Create Core DAX Measures

In the **Data** pane on the right, right-click `powerbi_weather_model` and select **New Measure**. Create the following 5 DAX measures:

### Measure 1: Total Observations
```dax
Total Observations = COUNTROWS('powerbi_weather_model')
```

### Measure 2: Average Temperature
```dax
Avg Temperature (C) = 
ROUND(AVERAGE('powerbi_weather_model'[temp_avg_c]), 1)
```

### Measure 3: Total Precipitation
```dax
Total Rainfall (mm) = 
ROUND(SUM('powerbi_weather_model'[precipitation_mm]), 1)
```

### Measure 4: Rainy Days Count
```dax
Rainy Days = 
CALCULATE(
    COUNTROWS('powerbi_weather_model'),
    'powerbi_weather_model'[precipitation_mm] > 0
)
```

### Measure 5: Data Completeness Rate
```dax
Data Completeness % = 
DIVIDE(
    CALCULATE(COUNTROWS('powerbi_weather_model'), NOT(ISBLANK('powerbi_weather_model'[temp_avg_c]))),
    COUNTROWS('powerbi_weather_model'),
    0
) * 100
```

## Step 3: Visual Layout Design (Single Page Executive Dashboard)

Arrange the following visual components on your canvas:

### 1. Top KPI Summary Cards (Row 1)
- **Card 1**: Field $\rightarrow$ `Total Observations` (Label: "Observations Processed")
- **Card 2**: Field $\rightarrow$ `Avg Temperature (C)` (Label: "Avg Temp (°C)")
- **Card 3**: Field $\rightarrow$ `Total Rainfall (mm)` (Label: "Cumulative Rainfall (mm)")
- **Card 4**: Field $\rightarrow$ `Rainy Days` (Label: "Total Rain Days")
- **Card 5**: Field $\rightarrow$ `Data Completeness %` (Label: "Sensor Completeness %")

### 2. Temperature Trends Over Time (Row 2, Left)
- **Visual Type**: **Line Chart**
- **X-axis**: `month_name` (or `observation_date`)
- **Y-axis**: `Avg Temperature (C)`, `temp_max_c` (Maximum), `temp_min_c` (Minimum)
- **Legend**: `station_name`
- **Insight**: Displays seasonal warming and cooling trajectories across stations.

### 3. Monthly Precipitation by Station (Row 2, Right)
- **Visual Type**: **Clustered Column Chart**
- **X-axis**: `month_name`
- **Y-axis**: `Total Rainfall (mm)`
- **Legend**: `station_name`
- **Insight**: Highlights which geographical locations experienced peak rainfall.

### 4. Seasonal Weather Comparison (Row 3, Left)
- **Visual Type**: **Donut Chart** or **Matrix**
- **Legend**: `season` (Winter, Spring, Summer, Fall)
- **Values**: `Total Rainfall (mm)` or `Avg Temperature (C)`

### 5. Station Geolocation Map (Row 3, Right)
- **Visual Type**: **Map**
- **Latitude**: `latitude`
- **Longitude**: `longitude`
- **Bubble size**: `Total Observations`
- **Tooltips**: `station_name`, `Avg Temperature (C)`, `Total Rainfall (mm)`

### 6. Interactive Slicers (Top or Side Panel)
- **Slicer 1**: `station_name` (Allows filtering to a specific city)
- **Slicer 2**: `season` (Filter by Winter, Spring, Summer, Fall)
- **Slicer 3**: `precip_category` (Filter by None, Light, Moderate, Heavy)

## Step 4: Connecting Directly to PostgreSQL (Optional Production Setup)

When you deploy PostgreSQL locally or on cloud:
1. In Power BI Desktop, click **Get Data** $\rightarrow$ **PostgreSQL Database**.
2. **Server**: `localhost:5432`
3. **Database**: `weatherflow`
4. **Data Connectivity Mode**: **Import** (or DirectQuery).
5. Select tables: `weather_observations`, `dim_date`, `dim_location`.
6. Power BI will automatically recognize foreign key relationships (`station_id` and `date_key`).
